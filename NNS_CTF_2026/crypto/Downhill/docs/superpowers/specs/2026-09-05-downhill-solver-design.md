# Downhill Solver Design

## Goal

Recover the binary sparse NTRU polynomial `f` from up to 500 deterministic NTRUSign signatures, derive the SHA-256 AES key, and decrypt the remote ciphertext without submitting the result.

## Design

The solver is a standalone Python entry point. It connects with TLS using the required SNI, parses the public key and ciphertext, submits deterministic chosen messages, and stores the resulting coefficient vectors. The recovery pipeline first exploits the exact NTRUSign relation: after rounding, each signature is a short linear combination of the cyclic-convolution basis generated by `(f,F)`. It estimates the leaked second-moment geometry, uses lattice reduction/candidate testing to identify a short direction, and filters candidates by the public-key relation and the required 73-one binary shape. Once `f` is recovered, it derives the AES-ECB key exactly as the challenge does and unpads the plaintext.

## Validation and safety

The implementation will include offline algebra/decryption checks using synthetic small examples where possible, explicit candidate-shape and public-key checks, TLS hostname verification, bounded signature count, and no CTF platform submission code. The writeup will explain the flow and mathematical intuition without embedding the full script.
