## Factoring calculation

The supplied M has 285 bits and `ord_M(17) = 21621600`.
For each exponent a, let `r = 17^a mod M` and `s = N/r mod M`.
Write `p = r + M*k`, `q = s + M*l`, with both k,l bounded by `(2^384 // M) + 1`.
Then, with `T = (N-r*s)/M`, solve:

`s*k + r*l = T (mod M)`.

Equivalently `k = u*l + v (mod M)` for `u = -r/s mod M`, `v = T/s mod M`.
Extended Euclid gives a basis of the two-dimensional lattice generated by `(M,0)` and `(u,1)`. The solver checks an explicit bound before rounding the coordinates of `(v,0)` in that basis. Every accepted result must multiply back to N.
