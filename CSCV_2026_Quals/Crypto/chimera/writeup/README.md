# Chimera

This is an offline RSA puzzle with a hidden modulus. The supplied archive contains a generator, 200 attestation samples, and the encrypted flag. The solution recovers the modulus through integer relations, checks it against every sample, and factors it using the restricted residue of one prime.

## Reproduction

From the challenge workspace, run:

```sh
/home/light/miniforge3/envs/sage/bin/python solver/solve.py
```

On another installation, use a Python interpreter that can import `sage.all`. The solver also requires `g++` and GMP development libraries. It reads `challenge/here`, compiles its embedded arithmetic helper into `script/`, and writes `flag.txt` only after verification. It does not contact a service or submit the flag.

## 1. Read the supplied construction

The generator records

\[
y_i = 3^{t\mathbin{\oplus}c_i}\pmod N,
\]

where each challenge and the fixed token have at most 128 bits. It encrypts the flag using RSA exponent 65537. Both primes have 384 bits, but only one has a specified residue:

\[
p\equiv17^a\pmod M,\qquad0\le a<\operatorname{ord}_M(17).
\]

The constant M has 285 bits; its specified generator has order 21,621,600. The generator does not impose the same residue restriction on q.

Both download URLs return the identical archive, SHA-256:

```text
9e59ff91aeb6b6ae6aec3c93f80875a6ddbad96c5f5e4fa14aff073901b06144
```

## 2. Recover N with integer relations

Expanding XOR bit by bit gives

\[
t\mathbin{\oplus}c_i=t+\sum_{j=0}^{127}c_{i,j}(1-2t_j)2^j.
\]

Let A have rows `[1, c_i,0, ..., c_i,127]`. Any integer vector w satisfying `w*A = 0` cancels the exponent, regardless of the unknown token. Consequently,

\[
N\mid\prod_{w_i>0}y_i^{w_i}-\prod_{w_i<0}y_i^{-w_i}.
\]

LLL applied to the rows of `[I_200 | 2^32 A]` produced 71 exact relations. The first relation produced a 389,174-bit product difference. The GCD with the second difference had 2,832 bits because of additional small factors. Dividing out primes below 10,000 left the 768-bit modulus:

## 3. Recover the token and validate N

The first 129 rows of A have rank 129 over the rationals. Invert this square matrix and clear denominators in each row. Multiplicative combinations of the observed values then isolate powers with exponent

\[
D_j(1-2t_j)2^j.
\]

Each observed product must equal either `3^(D_j*2^j) mod N` or its inverse. These two cases identify token bit 0 or 1, respectively. The recovered token is

```text
207501371779773263714741078953073691351
```

Direct evaluation of `pow(3, token ^ challenge, N)` matches all 200 supplied values.

## 4. Convert each residue guess to a bounded congruence

For an exponent candidate a, define

\[
r=17^a\bmod M,\qquad s=Nr^{-1}\bmod M.
\]

A correct candidate permits

\[
p=r+Mk,\qquad q=s+M\ell,
\]

where k and l are about 100 bits. Expanding their product and dividing by M gives

\[
T=(N-rs)/M,\qquad sk+r\ell\equiv T\pmod M.
\]

Set `u = -r/s mod M` and `v = T/s mod M`. The remaining equation is

\[
k\equiv u\ell+v\pmod M.
\]

Use the lattice generated by `(M,0)` and `(u,1)`. Extended Euclid supplies a basis with coordinates roughly the square root of M. A correct solution gives the lattice point `(v-k,-l)`, very close to `(v,0)` relative to the basis size.

For each basis vector `(x,y)`, the implementation checks

\[
2X(|x|+|y|)<M,\qquad X=\lfloor2^{384}/M\rfloor+1.
\]

Since the determinant has absolute value M, these bounds ensure that the small displacement `(k,l)` changes both basis coordinates by less than one half. Rounding the coordinates of `(v,0)` therefore recovers the correct lattice point whenever that residue is correct. Candidates still must satisfy the bounds on k and l and the exact product equation `p*q == N`.

This avoids a separate higher-dimensional lattice reduction for every exponent. The compiled GMP implementation checked about 145,000 candidates per second on this machine. Synthetic instances at exponents 0, 1, 137, 12345678 and 21621599 confirmed the arithmetic before the full search.

## 5. Decrypt and verify

Compute

\[
d=65537^{-1}\bmod(p-1)(q-1),\qquad m=c^d\bmod N.
\]

The final solver verifies both primality proofs, both 384-bit lengths, `p*q == N`, the specified residue of p, all 200 attestations, and RSA re-encryption of m. The recovered bytes are:

```text
CSCV2026{ch1m3r4_h1dd3n_m0dulus_th3n_b1453d_k3yg3n_2026}
```

The flag is verified locally and has not been submitted.

## Investigation notes

The raw GCD needed small-factor removal, so its bit length alone was insufficient evidence of N. The later token reconstruction supplied a direct check against all observations. A subgroup-membership check also showed that N itself is not in the subgroup generated by 17 modulo M; the factorization therefore uses only the restriction actually stated for p.

No external cryptographic writeup or exploit code was used. The source and recorded values supplied the equations. The only external retrieval was the second published archive, whose contents matched the first.
