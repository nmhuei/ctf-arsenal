def check(password):

        return "Password contains invalid characters."

## 2. Vulnerability & Mathematical Analysis

1. **NumPy Integer Overflow**:
   - On 64-bit systems, `np.array(..., dtype=int)` defaults to 64-bit signed integer (`int64`).
   - `array.prod()` performs C integer multiplication wrapping around modulo $2^{64}$.
   - We need:
     $$\prod_{i=1}^N \text{ord}(c_i) \equiv \sum_{i=1}^N \text{ord}(c_i) \pmod{2^{64}}$$
     where $\text{sum}$ is an odd prime.

2. **Parity Constraint**:
   - Since $\text{sum} \ge 48$ is a prime, $\text{sum}$ must be an **odd prime**.
   - If any character $c_i$ had an even ASCII code, $\text{prod} \bmod 2^{64}$ would be even, which contradicts $\text{prod} \equiv \text{sum} \pmod{2^{64}}$.
   - Therefore, **100% of the characters in the password must have odd ASCII codes** (32 valid characters in `[0-9a-zA-Z_]`).

3. **2-adic Discrete Logarithm Reduction**:
   - The multiplicative group $(\mathbb{Z} / 2^{64}\mathbb{Z})^\times \cong \mathbb{Z}_2 \times \mathbb{Z}_{2^{62}}$ is generated by $-1$ and $5$.
   - Any odd integer $x$ can be decomposed uniquely as:
     $$x \equiv (-1)^s \cdot 5^k \pmod{2^{64}}$$
     where $k = \text{dlog}_5(x \cdot (-1)^s) \pmod{2^{62}}$.
   - This transforms the non-linear modular product equation into a linear integer equation:
     $$\sum_{j=1}^{32} a_j \text{dlog}_5(x_j) \equiv \text{dlog}_5(S_{\pm}) \pmod{2^{62}}$$
     $$\sum_{j=1}^{32} a_j \text{ord}(c_j) = S$$

4. **Lattice Reduction (LLL)**:
   - Constructing a $35 \times 36$ lattice using Kannan's embedding with LLL reduction finds non-negative integer character counts $a_j$ in **0.05 seconds**.
