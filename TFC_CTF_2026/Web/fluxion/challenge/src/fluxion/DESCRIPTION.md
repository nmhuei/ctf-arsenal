# Fluxion

**Category:** Web  **Difficulty:** Hard

Fluxion is a **durable workflow engine** with a live observability console. Workflows run for a long
time, pause on external signals (webhooks and hooks), and resume exactly where they left off — every
run, step, and hook streamed to the dashboard in real time.

**Connect:** `http://<HOST>:3000`

Flag format: `TFC{...}`
